# 06. 수용 기준 (PM-AC)

- 입력: PM-US, PM-DOMAIN(INV), PM-DEC
- 모든 단계는 이 번호(`AC-xx-n`, `NFR-xx`)를 그대로 쓴다. ★ = 예외 시나리오 AC.
- "새로고침 없이" = 브라우저 전체 문서 재요청 없이 화면이 바뀜 (KANT-C13).

## 1. 기능 AC

### US-01 메인
- AC-01-1: Given 방문자, When `/` 접속, Then Header·Footer, 책방 한 줄 소개, 4개 테마 입구, 추천 책 카드 1개 이상, 구독 안내가 보인다.
- AC-01-2: Given 메인, When 테마 입구·책 카드·Header 메뉴를 누름, Then 새로고침 없이 해당 화면으로 이동한다.
- ★AC-01-3: Given 상품 데이터 조회 실패, When `/` 접속, Then 추천 영역에 안내 문구가 보이고 나머지 영역과 Header·Footer는 정상이다.

### US-02 책방 소개
- AC-02-1: Given 방문자, When Header의 책방 소개를 누름, Then 소개 글·사진과 "예시" 표시가 보인다.
- ★AC-02-2: Given 사진 URL이 깨짐, When 소개 화면 표시, Then 글은 그대로 보이고 사진 자리는 원래 비율의 대체 영역이다.

### US-03 목록·테마 서가
- AC-03-1: Given 상품 n권, When `/products` 접속, Then 카드 n개가 그리드로 보이고 각 카드에 표지·제목·저자·가격·테마가 있다.
- AC-03-2: Given 테마 '자연' 선택, When 목록 표시, Then 테마가 '자연'인 책만 보인다. "전체"를 고르면 n권 전부 보인다.
- AC-03-3: Given 재고 0인 책, When 목록 표시, Then 그 카드에 "품절"이 보인다.
- ★AC-03-4: Given 책이 0권인 테마, When 그 테마 선택, Then "이 서가는 아직 준비 중입니다"가 보인다.
- ★AC-03-5: Given 존재하지 않는 테마 값으로 접근, When 목록 표시, Then 전체 목록과 안내가 보이고 에러 화면이 아니다.

### US-04 상세
- AC-04-1: Given 존재하는 ID, When `/products/[id]` 접속, Then 그 ID의 책 정보가 보이고, 첫 콘텐츠 블록이 책방지기 노트이며 노트 글자 크기가 본문보다 크다.
- AC-04-2: Given 상세, When 화면 표시, Then 노트 아래에 표지·제목·저자·출판사·테마·가격·[장바구니 담기]가 있고 출판사 소개는 접힌 상태다.
- ★AC-04-3: Given 존재하지 않는 ID, When 접속, Then 크래시 없이 "상품을 찾을 수 없습니다"와 목록으로 가는 링크가 보인다. (KANT-C14)
- ★AC-04-4: Given 재고 0, When 상세 표시, Then [장바구니 담기]가 비활성이고 "품절"이 보인다.

### US-05 로그인
- AC-05-1: Given 비로그인, When [로그인], Then 카카오·네이버 두 버튼만 보인다 (아이디·비밀번호 칸 없음).
- AC-05-2: Given 카카오(또는 네이버) 동의 완료, When 돌아옴, Then 로그인 상태가 되고 로그인 전 화면으로 돌아오며 Header에 마이페이지·로그아웃이 보인다.
- AC-05-3: Given 로그인 상태, When 로그아웃, Then 비회원 상태가 되고 마이페이지 접근 시 로그인 화면으로 간다.
- ★AC-05-4: Given 제공자 화면에서 취소, When 돌아옴, Then 로그인 화면에 "로그인이 취소되었습니다"가 보인다.

### US-06 배송지
- AC-06-1: Given 배송지 없는 회원, When 주문서·구독 신청, Then 배송지 입력 칸과 수집 목적·항목·보관 기간 안내, 동의 체크가 있다.
- AC-06-2: Given 저장된 배송지, When 다음 주문서, Then 자동으로 채워져 있다. 마이페이지에서 고치면 다음 주문부터 바뀐다.
- ★AC-06-3: Given 필수 항목 누락 또는 동의 안 함, When 저장, Then 저장되지 않고 해당 칸에 안내가 보인다.
- ★AC-06-4: Given 이미 발송된 주문, When 배송지 수정, Then 그 주문의 배송지는 바뀌지 않는다.

### US-07 관리자 진입
- AC-07-1: Given 책방지기 계정, When 관리자 경로 접속, Then 관리자 첫 화면에서 서재 작업·주문 목록·주소록·재고·인사 편지·작별 편지함으로 갈 수 있다.
- ★AC-07-2: Given 일반 회원 또는 비회원, When 관리자 화면·관리자 데이터 요청, Then 거부되고(NFR-05) 관리자 데이터가 하나도 오지 않는다.

### US-08 장바구니
- AC-08-1: Given 비회원, When 상세에서 [장바구니 담기], Then 안내가 보이고 Header 장바구니 개수가 1 늘어난다.
- AC-08-2: Given 장바구니, When 수량 변경·빼기, Then 합계(책 금액 + 배송비)가 즉시 바뀐다.
- AC-08-3: Given 비회원 장바구니 2권, When 로그인, Then 장바구니에 2권이 그대로 있다.
- ★AC-08-4: Given 재고 3, When 수량을 4로 올림, Then 3에서 멈추고 "남은 수량은 3권입니다".
- ★AC-08-5: Given 담아 둔 책이 품절됨, When `/cart` 열기, Then 그 줄에 "품절"이 보이고 합계·주문에서 빠진다.

### US-09 주문·결제
- AC-09-1: Given 비회원, When [주문하기], Then 로그인 후 주문서로 돌아온다.
- AC-09-2: Given 회원·배송지·재고 충분, When 테스트 결제 성공, Then 주문 `paid`, 재고가 수량만큼 줄고, 장바구니에서 빠지고, 결제 완료 화면이 보인다.
- AC-09-3: Given 주문서, When 금액 표시, Then 금액은 서버가 상품 가격·수량·배송비로 계산한 값이다.
- ★AC-09-4: Given 결제창, When 닫기·인증 실패, Then "결제가 완료되지 않았습니다", 장바구니 유지, 재고 변화 없음.
- ★AC-09-5: Given 결제 요청 금액이 서버 계산과 다름, When 승인 단계, Then 승인하지 않고 실패 화면.
- ★AC-09-6: Given 결제 직전 재고 부족, When 승인 단계, Then 승인하지 않고 부족한 책을 안내한다.
- ★AC-09-7: Given 같은 결제 성공 응답 2회, When 처리, Then 주문 확정·재고 차감은 1회 (NFR-08).
- ★AC-09-8: Given 배송지 없음, When 주문서, Then [결제하기]가 비활성.

### US-10 주문 상태·취소
- AC-10-1: Given 회원 주문 3건, When 마이페이지, Then 3건이 날짜·책·금액·상태 글자(주문 확인/발송됨/주문 취소됨)로 보이고 창가 그림은 없다.
- AC-10-2: Given `주문 확인` 주문, When [주문 취소], Then 전액 환불(테스트), 재고 복구, 상태 `주문 취소됨`.
- ★AC-10-3: Given `발송됨` 주문, When 화면·직접 요청으로 취소 시도, Then 버튼이 없고 요청은 거부된다.
- ★AC-10-4: Given 환불 실패, When [주문 취소], Then 상태 `주문 확인` 유지 + 다시 시도 안내.
- ★AC-10-5: Given 같은 주문 취소 2회, When 처리, Then 환불·재고 복구 1회.
- ★AC-10-6: Given 다른 회원 주문 ID, When 조회·취소, Then 보이지 않고 거부.

### US-11 관리자 주문 목록
- AC-11-1: Given `paid` 주문들, When 주문 목록, Then 오래된 순으로 주문일·이름·책·수량·배송지가 보인다.
- AC-11-2: Given `paid` 주문, When [발송 처리], Then `shipped`, 회원 마이페이지에 "발송됨".
- ★AC-11-3: Given `paid`가 아닌 주문, When 목록, Then [발송 처리]가 없고 직접 요청도 거부.

### US-12 손편지 구독 신청
- AC-12-1: Given 회원·활성 구독 없음, When 편지지 화면, Then 체크박스·설문 없이 자유 글 칸 1개, 구독료(예시), 결제일 안내, 배송지가 있다.
- AC-12-2: Given 편지 1~2000자·배송지, When [우체통에 편지 넣기] + 테스트 첫 결제 성공, Then 구독 `active`, 회차 1 `letter_arrived`, 편지 저장.
- AC-12-3: Given 결제 확정, When 화면, Then 0.3초 안에 봉투 전환 시작, 3초 안에 완료 메시지와 [마이페이지 창가 보기].
- AC-12-4: Given 움직임 줄이기 설정, When 제출 성공, Then 전환 없이 완료 메시지가 바로 보인다.
- ★AC-12-5: Given 빈 편지 또는 2001자, When 제출, Then 제출되지 않고 안내.
- ★AC-12-6: Given 활성 구독 있음, When 신청 화면 접근, Then "이미 구독 중입니다"와 마이페이지 링크.
- ★AC-12-7: Given 첫 결제 실패, When 제출, Then 구독·회차 생성 없음, 편지 글은 화면에 남고, 애니메이션 없이 실패 안내.

### US-13 매달 자동결제·회차
- AC-13-1: Given 1월 10일 신청, When 2월 10일 자동결제 성공, Then 회차 2 생성. 보관 편지가 있으면 `letter_arrived`, 없으면 `awaiting_letter`.
- AC-13-2: Given 1월 31일 신청, When 2월, Then 2월 말일에 결제 시도.
- ★AC-13-3: Given 자동결제 실패, When 처리, Then 회차 없이 구독 `ended`, 마이페이지에 "결제가 되지 않아 구독이 마무리되었습니다"와 다시 신청 링크.
- ★AC-13-4: Given `cancelled`·`ended` 구독, When 결제일, Then 결제 시도 0회.
- ★AC-13-5: Given 같은 달 결제 확정 2회 수신, When 처리, Then 회차 1개.

### US-14 다음 회차 편지
- AC-14-1: Given 최근 회차 `awaiting_letter`, When [편지 쓰기]→제출, Then 그 회차 `letter_arrived`, 결제 없음, 봉투 전환 재생.
- AC-14-2: Given 최근 회차가 `reading` 이후, When 편지 제출, Then 다음 회차 편지로 보관되고 다음 회차가 열리면 `letter_arrived`로 시작.
- ★AC-14-3: Given 보관 편지 있음, When [편지 쓰기], Then 보관 편지 수정 화면이 열린다 (회차당 1통).
- ★AC-14-4: Given 활성 구독 없음, When 편지 쓰기 접근, Then 버튼 없음, 구독 안내로 이동.

### US-15 서점 창가
- AC-15-1: Given 최근 회차 상태 각각(`awaiting_letter`·`letter_arrived`·`reading`·`shipped`·`unboxed`), When 마이페이지, Then US-15 정의의 그림·문구가 보인다. `shipped`에는 "책이 서점 문을 나섰습니다".
- AC-15-2: Given 책방지기가 [읽기 시작], When 회원이 마이페이지를 다시 열기, Then 촛불이 켜져 있다.
- AC-15-3: Given 어떤 상태, When 창가 표시, Then 송장 번호·배송 단계 숫자가 없다.
- ★AC-15-4: Given 구독 이력 없음, When 마이페이지, Then 창가 대신 구독 안내.
- ★AC-15-5: Given `cancelled`·`ended`, When 마이페이지, Then 마지막 상태 그림과 마무리 안내.

### US-16 편지 읽기·읽기 시작
- AC-16-1: Given 처리할 회차, When 서재 작업 화면, Then 한 페이지에 위→아래 순서로 ①편지 ②매칭·답장·엽서 ③힌트·발송이 있고 좌우 분할이 없다.
- AC-16-2: Given 회차 선택, When 편지 열람, Then 편지 전문이 보이고 회차 상태는 그대로다 (촛불 안 켜짐).
- AC-16-3: Given `letter_arrived` 회차, When [읽기 시작], Then `reading`.
- AC-16-4: Given 이번 달 편지 없는 `awaiting_letter` 회차, When 선택, Then 가장 최근 편지와 "이번 달 편지 없음"이 보이고 [읽기 시작]으로 `reading`.
- ★AC-16-5: Given `reading` 이후 회차, When 화면, Then [읽기 시작]이 없고 직접 요청도 상태를 바꾸지 않는다.

### US-17 매칭·답장·엽서
- AC-17-1: Given `reading` 회차, When 제목·저자 검색, Then 일치하는 책과 재고 수가 보인다.
- AC-17-2: Given 책 선택·답장 작성·엽서 1장 업로드, When 화면을 떠났다 돌아옴, Then 작성 내용이 남아 있다.
- ★AC-17-3: Given 재고 0인 책, When 검색 결과, Then "품절"이고 선택할 수 없다.
- ★AC-17-4: Given 허용되지 않는 사진 형식·크기, When 업로드, Then 올라가지 않고 안내.
- ★AC-17-5: Given 검색 결과 0, When 검색, Then "찾는 책이 없습니다".
- ★AC-17-6: Given `reading`이 아닌 회차, When 화면, Then 매칭 영역이 비활성.

### US-18 힌트·발송·코드
- AC-18-1: Given 매칭 책·답장·힌트(1~100자) 있음, When [발송], Then 6자리 숫자 코드 생성, 매칭 책 재고 1 감소, 회차 `shipped`, 코드가 크게 보인다.
- AC-18-2: Given `shipped` 회차, When 다시 열기, Then 같은 코드가 보인다.
- ★AC-18-3: Given 매칭 책·답장·힌트 중 하나 없음, When 화면, Then [발송] 비활성 + 빠진 항목 안내.
- ★AC-18-4: Given 발송 직전 매칭 책 재고 0, When [발송], Then 발송 안 되고 다른 책 고르기 안내.
- ★AC-18-5: Given [발송] 2회, When 처리, Then 코드 1개, 재고 감소 1.
- ★AC-18-6: Given 발급된 미사용 코드들, When 새 코드 생성, Then 기존 미사용 코드와 겹치지 않는다.

### US-19 블라인드 북·언박싱
- AC-19-1: Given `shipped` 회차, When 나의 서가, Then 실루엣 표지·힌트·코드 입력칸이 보이고 제목·표지·저자·답장·엽서는 없다.
- AC-19-2: Given `shipped` 회차, When 회원이 받는 그 화면의 HTML·데이터 응답 전체를 검사, Then 책 제목·저자·표지 URL·답장·엽서 URL 문자열이 0건 (NFR-06).
- AC-19-3: Given 맞는 코드, When [열기], Then 2초 안에 표지 공개가 끝나고 제목·저자·답장·엽서가 보이며 회차 `unboxed`.
- AC-19-4: Given 움직임 줄이기, When 맞는 코드, Then 전환 없이 즉시 표시.
- ★AC-19-5: Given 틀린 코드, When [열기], Then "코드가 맞지 않아요" + 남은 시도 횟수, 책 정보 미노출.
- ★AC-19-6: Given 연속 실패가 제한 횟수 도달, When 다시 입력, Then 잠금 시간 동안 거부 + 다시 시도 가능 시각 (NFR-07).
- ★AC-19-7: Given 5자리·문자 포함, When 제출, Then 제출되지 않음.
- ★AC-19-8: Given 다른 회원 회차의 맞는 코드, When 내 계정에서 입력, Then 틀린 코드와 같은 응답, 실패 횟수 1 증가.
- ★AC-19-9: Given 해지한 회원의 `shipped` 회차, When 맞는 코드, Then 언박싱된다.

### US-20 한 줄 메모
- AC-20-1: Given 언박싱한 책, When 메모(1~100자) 저장, Then 메모와 저장 날짜가 보인다.
- AC-20-2: Given 메모 있음, When 고치기·지우기, Then 반영되고 날짜는 마지막 저장일.
- AC-20-3: Given 메모 화면, When 표시, Then 별점·공개·공유·댓글 요소가 없다.
- ★AC-20-4: Given 101자, When 저장, Then 저장 안 됨 + 글자 수 표시.
- ★AC-20-5: Given 언박싱 전 책, When 나의 서가, Then 메모 칸이 없다.
- ★AC-20-6: Given 책방지기 계정, When 관리자 화면 전체, Then 회원 메모가 보이지 않는다.

### US-21 해지
- AC-21-1: Given 활성 구독, When [구독 마무리하기], Then 맨 위에 마지막 인사 편지(손님별 글, 없으면 기본 편지), 그 아래 자유 글 칸과 "결제된 회차는 발송됩니다" 안내.
- AC-21-2: Given 해지 화면, When [구독을 마무리합니다] 1회 (글 비움 포함), Then 즉시 `cancelled`, 마무리 화면, 이후 자동결제 0회.
- AC-21-3: Given 해지 흐름 전체, When 화면 검사, Then 혜택 경고·쉬어가기·재확인 팝업·필수 설문이 없다 (해지까지 클릭 2회: 진입 + 마무리).
- AC-21-4: Given 이번 회차 결제 완료·미발송, When 해지, Then 그 회차는 계속 처리되어 발송될 수 있다.
- ★AC-21-5: Given 활성 구독 없음, When 해지 화면 접근, Then 마이페이지로 이동.
- ★AC-21-6: Given 마무리 버튼 2회, When 처리, Then 해지 1회.

### US-22 주소록 엑셀
- AC-22-1: Given 활성 구독자 k명, When [주소록 엑셀 받기], Then k행 + 머리글(이름·연락처·우편번호·주소·상세주소)의 엑셀 파일이 내려받아진다. 해지·종료 회원은 없다.
- ★AC-22-2: Given 활성 구독자 0명, When 받기, Then 머리글만 있는 파일 또는 "구독 중인 손님이 없습니다".
- ★AC-22-3: Given 비관리자, When 주소록 요청, Then 거부 (NFR-05).

### US-23 손님별 인사 편지 (Should)
- AC-23-1: Given 활성 구독 회원, When 인사 편지 저장, Then 그 회원 해지 화면에 그 글이 보인다.
- ★AC-23-2: Given 인사 편지 없음, When 그 회원 해지 화면, Then 기본 편지가 보인다.
- ★AC-23-3: Given 해지한 회원, When 인사 편지 수정, Then 거부.

### US-24 작별 편지함 (Should)
- AC-24-1: Given 해지 3건, When 작별 편지함, Then 최신순으로 날짜·이름·글. 빈 글은 "남긴 글 없음".
- ★AC-24-2: Given 비관리자, When 접근, Then 거부.

### US-25 재고 수량 (Should)
- AC-25-1: Given 재고 화면, When 수량 0→5 저장, Then 상세·목록에서 품절이 사라지고 담을 수 있다.
- AC-25-2: Given 재고 화면, When 표시, Then 수량 외 책 정보는 고칠 수 없다.
- ★AC-25-3: Given -1 또는 문자, When 저장, Then 저장 안 됨.

### US-26 README·시연
- AC-26-1: Given 처음 받은 저장소, When README의 명령대로 실행, Then 로컬에서 메인이 뜬다 (환경 변수 값은 README 안내대로 준비).
- AC-26-2: Given README, When 확인, Then 소개, 컴포넌트 텍스트 트리, 실행 명령, 화면 캡처, 환경 변수 목록(값 제외), 테스트 결제·로그인 안내가 있다 (KANT-C17).
- AC-26-3: Given 시연 흐름(`07-screens.md` §4), When 리허설, Then 5분 안에 끝난다.
- ★AC-26-4: Given 필수 환경 변수 누락, When 실행, Then 무엇이 빠졌는지 알 수 있는 메시지가 보인다.
