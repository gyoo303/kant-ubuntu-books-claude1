# 07. 화면 구성 & 와이어프레임 (PM-SCR)

- 입력: PM-US, PM-AC, PM-DOMAIN. UX-CTX-ORCH 미배포.
- 경로는 **후보**다(최종은 Architect). 색·폰트·일러스트는 UI/UX 몫이고, 여기서는 구성 요소와 우선순위만 정한다.

## 3. KANT 핵심 3페이지 와이어프레임 (KANT-R1, C2)

### SCR-01 메인 (`/`)
```
┌ Header ─────────────────────────────────────────┐
│ [로고] 테마 서가 · 책방 소개 · 손편지 구독   [장바구니 n] [로그인] │
├─────────────────────────────────────────────────┤
│ ① 책방 한 줄 소개 (어은동 골목, 느린 책방)  ← REQ-001, 004 │
│    [책방 소개 보기]                                │
├─────────────────────────────────────────────────┤
│ ② 테마 입구 4칸: 자연 | 식문화 | 생태 | 로컬  ← REQ-007   │
│    (모바일 2×2, PC 1×4)                            │
├─────────────────────────────────────────────────┤
│ ③ 책방지기가 고른 책: ProductCard × 4 (그리드)       │
│    [전체 서가 보기]                                │
├─────────────────────────────────────────────────┤
│ ④ 손편지 구독 안내: "편지를 보내면 책방지기가 한 권을 골라   │
│    보내드려요" [손편지 띄우기]           ← REQ-018    │
└ Footer ─────────────────────────────────────────┘
데이터 실패 → ③ 자리에 안내 문구 (AC-01-3)
```
필수 시각 요소: Header, 한 줄 소개, 테마 입구 4개, ProductCard 그리드, 구독 안내, Footer

### SCR-03 상품 목록·테마 서가 (`/products`)
```
┌ Header ─────────────────────────────────────────┐
│ 서가 제목 ("전체 서가" 또는 "자연의 서가")              │
│ 테마 설명 한 줄 (선택한 테마일 때)                     │
│ ThemeSelector: [전체] [자연] [식문화] [생태] [로컬]      │
├─────────────────────────────────────────────────┤
│ ProductCard 그리드 (.map)                         │
│  360px: 2열 / 768px: 3열 / 1280px: 4열, 균일 간격     │
│  ┌──────┐ ┌──────┐                               │
│  │표지 3:4│ │표지 3:4│  ← object-cover             │
│  │제목    │ │제목    │                              │
│  │저자    │ │저자 품절│                              │
│  │가격·테마│ │가격·테마│                              │
│  └──────┘ └──────┘                               │
└ Footer ─────────────────────────────────────────┘
0권 → "이 서가는 아직 준비 중입니다" (AC-03-4)
```
필수 시각 요소: 서가 제목, 테마 선택, 균일 간격 카드 그리드, 카드별 표지·제목·저자·가격·테마·품절

### SCR-04 상품 상세 (`/products/[id]`)
```
┌ Header ─────────────────────────────────────────┐
│ ① 책방지기 노트 — 최상단, 본문보다 큰 글씨  ← REQ-009    │
│    "책방지기의 한마디" 머리말 + 노트 전문 (한 줄 ≤ 40em)   │
├─────────────────────────────────────────────────┤
│ ② [표지 3:4 object-cover] │ 제목 / 저자 / 출판사       │
│    (모바일: 위아래 배치)    │ 테마 · 가격 · 재고 상태     │
│                          │ [수량] [장바구니 담기]       │
├─────────────────────────────────────────────────┤
│ ③ 출판사 소개 (접힘, [펼치기])                        │
│ ④ [같은 테마 서가로] [전체 서가로]                     │
└ Footer ─────────────────────────────────────────┘
없는 ID → "상품을 찾을 수 없습니다" + [목록으로] (AC-04-3)
품절 → [장바구니 담기] 비활성 + "품절" (AC-04-4)
```
필수 시각 요소: 노트(최상단·큰 글씨), 표지, 제목·저자·출판사·테마·가격·재고, 장바구니 버튼, 접힌 출판사 소개, 서가로 돌아가기

## 4. 그 밖의 화면 (구성 요소·상태)
| SCR | 구성 요소 (위→아래) | 상태별 표시 |
|---|---|---|
| SCR-02 | 소개 글, 책방 사진, 위치·운영 안내 ("예시") | 사진 실패 → 비율 유지 대체 영역 |
| SCR-05 | 안내 한 줄, [카카오로 시작] [네이버로 시작] | 취소 → "로그인이 취소되었습니다", 오류 → 다시 시도 |
| SCR-06 | ① 서점 창가(BookshopWindow) + 상태 문구·[편지 쓰기] ② 나의 서가 바로가기 ③ 주문 내역(상태 글자, [주문 취소]) ④ 배송지 ⑤ [구독 마무리하기] (작게, 맨 아래) | 구독 없음 → 창가 대신 구독 안내 / `ended` → 결제 실패 안내 + 다시 신청 / `cancelled` → 마무리 안내 |
| SCR-07 | ShippingAddressFields, [저장] | 오류 칸별 안내 |
| SCR-08 | 책 줄(표지·제목·수량·금액·빼기), 합계(책 + 배송비 "예시"), [주문하기] | 비어 있음 → 서가 링크 / 품절 줄 표시 |
| SCR-09 | 책 목록, 배송지, 금액(서버 계산), 환불 안내("예시"), [결제하기] | 배송지 없음 → 버튼 비활성 |
| SCR-10 | 성공: 주문 요약 + 마이페이지 링크 / 실패: 사유 + 장바구니 링크 | — |
| SCR-11 | 구독 방식 설명(매달 1권·자동결제·블라인드 북·코드 언박싱), 구독료("예시"), [손편지 띄우기] | 구독 중 → "이미 구독 중입니다" |
| SCR-12 | 편지지(LetterPaper, 1~2000자), (신청 시) 구독료·결제일·배송지, [우체통에 편지 넣기] → 봉투 전환 → 완료 메시지 | 실패 → 편지 유지 + 안내 / 보관 편지 있음 → 수정 모드 |
| SCR-13 | 회차별 카드 최신순: 블라인드(BlindBookCard) 또는 열린 책(표지·제목·저자, 답장, 엽서, 한 줄 메모 칸) | 틀린 코드 / 잠금 / 언박싱 전환 |
| SCR-14 | ① 마지막 인사 편지 ② 작별 글 칸(선택) ③ "결제된 회차는 발송됩니다" ④ [구독을 마무리합니다] → 마무리 화면 | 경고·팝업·유예 없음 |
| SCR-15 | 관리자 메뉴: 서재 작업 화면(처리할 회차 수), 주문 목록(발송 대기 수), [주소록 엑셀 받기], 재고, 인사 편지, 작별 편지함 | 비관리자 → 거부 |
| SCR-16 | 한 페이지, 좌우 분할 없음. ① 처리할 회차 목록 → 편지 전문 → [읽기 시작] ② 책 검색·선택(재고 표시), 답장, 엽서 사진 ③ 힌트, [발송] → 6자리 코드 크게 표시 | `reading` 전에는 ②③ 비활성, 빠진 항목 안내 |
| SCR-17 | 발송 대기 주문 목록(오래된 순): 주문일·이름·책·수량·배송지, [발송 처리] | 대기 0 → 안내 |
| SCR-18 | 구독 중 손님 목록 → 인사 편지 쓰기·저장, 기본 편지 미리보기 | 해지 손님 → 읽기만 |
| SCR-19 | 작별 글 목록(최신순): 날짜·이름·글 | 빈 글 → "남긴 글 없음" |
| SCR-20 | 책 목록: 제목·저자·현재 수량, 수량 입력, [저장] | 음수·문자 → 저장 안 됨 |

### 관리자 화면 배치 (D-005)
- REQ-038의 "위→아래 한 화면"은 SCR-16(구독자 작업)에만 적용한다. 주문 목록·재고·인사 편지·작별 편지함·주소록은 SCR-15에서 들어가는 별도 화면이라 SCR-16 흐름을 복잡하게 만들지 않는다.

## 5. 시연 흐름 초안 (KANT-C18, US-26, 약 5분)
| 순서 | 화면 | 보여줄 것 | 근거 |
|---|---|---|---|
| 1 | SCR-01 | 메인 구성, 테마 입구 → 새로고침 없는 이동 | R1, R7 |
| 2 | SCR-03 | 전체 목록(.map 그리드) → '자연' 테마 서가, 360px/1280px 전환 | R5, R8 |
| 3 | SCR-04 | 카드 클릭 → 상세, 노트 최상단 | R6 |
| 4 | SCR-04 | 주소창에 없는 ID → "상품을 찾을 수 없습니다" | R9 |
| 5 | SCR-08 → 05 → 09 → 10 | 비회원 장바구니 → 카카오 로그인 → 테스트 결제 → 완료 | REQ-013~016 |
| 6 | SCR-11 → 12 | 손편지 쓰기 → [우체통에 편지 넣기] 봉투 전환 | REQ-018~020 |
| 7 | SCR-16 → SCR-06 | (관리자 창) 편지 열람 → [읽기 시작] → (회원 창 새로고침) 촛불 켜짐 | REQ-023, 039 |
| 8 | SCR-16 → SCR-06 | 매칭·답장·힌트 → [발송] 코드 확인 → 회원 창가 우체통 불빛 | REQ-024, 040~042 |
| 9 | SCR-13 | 블라인드 북 → 틀린 코드 1회 → 맞는 코드 → 언박싱 → 한 줄 메모 | REQ-025~032 |
| 10 | SCR-14 | 인사 편지 → 작별 글 → [구독을 마무리합니다] 즉시 해지 | REQ-033~036 |
- 준비물: 회원 창·관리자 창 두 개, 테스트 결제 카드, seed 데이터(회차 진행용), README 캡처.
