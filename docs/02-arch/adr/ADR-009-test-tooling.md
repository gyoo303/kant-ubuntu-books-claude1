# ADR-009: 테스트 도구
- 상태: Accepted (user, 2026-10-21)
- 관련 계층: [레이어]
- 근거: RISK-11, DRV-Q-05, `01-drivers.md` 저장소 현황(`node --test` + `tsx` 설치됨, 0개 실행 문제)

## 맥락
저장소에는 이미 `node:test` + `tsx`가 있다. 현재 `npm test`는 Windows에서 경로 패턴이 펼쳐지지 않아 0개를 실행하고 통과한다. 테스트 1순위는 I/O 없는 `lib/domain` 순수 함수다.

## 검토한 옵션
| 옵션 | 장점 | 단점 | AI 부채 영향 | KANT 영향 | 되돌리기 비용 |
|---|---|---|---|---|---|
| A 기존 `node:test` + `tsx` 유지, `scripts/run-tests.mjs`로 파일 찾기·0개 실패 처리 | 새 의존성 0, 이미 설치 | 스냅샷·브라우저 테스트 기능 없음 | 낮음 | 충족 (C15 빌드와 무관) | 낮음 |
| B `vitest` 추가 | 감시 모드·리포트 편리 | 같은 일을 하는 도구 2개(기존 node:test와 중복), 설정 파일 추가 | 중 | 무관 | 낮음 |

## 결정 / 추천
결정: **A** — 의존성을 늘리지 않고 0개 실행 문제만 고친다. 화면 검증은 QA의 내장 브라우저 조작으로 한다.
- 함께 승인됨: `server-only` 패키지 추가 (Next 16 문서가 서버 전용 모듈 표시에 이 패키지 설치를 안내, CONV-10). 현재 미설치.
