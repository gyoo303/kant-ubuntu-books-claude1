# ADR-007: 외부 입력 런타임 검증
- 상태: Accepted (user, 2026-10-21)
- 관련 계층: [레이어]
- 근거: DRV-Q-01, DRV-Q-02, RISK-01, ADR-002(모든 쓰기가 JSON Route Handler)

## 맥락
쓰기 API가 약 25개이고, 토스 리다이렉트 쿼리·URL 파라미터·폼 JSON을 받는다. `any` 금지, 외부 입력은 런타임 검증이 필수다. 현재 검증 라이브러리가 없다.

## 검토한 옵션
| 옵션 | 장점 | 단점 | AI 부채 영향 | KANT 영향 | 되돌리기 비용 |
|---|---|---|---|---|---|
| A 직접 작성한 타입 가드 함수 (의존성 0) | 패키지 추가 없음 | API마다 손으로 쓴 검증 → 빠짐·불일치 위험, 타입과 검증이 따로 놂 | 높음 | 무관 | 낮음 |
| B `zod` 1개 추가: 스키마에서 타입 추론(`z.infer`), `safeParse`로 400 응답 | 타입과 검증이 한 곳, 널리 쓰여 하위 에이전트 정확도 높음 | 의존성 1개 | 낮음 | 무관 | 낮음 |

## 결정 / 추천
결정: **B `zod`** (버전은 설치 시점 최신 4.x로 고정, `package-lock.json` 기록)

## 결과
- 스키마 위치: `lib/api/schemas.ts` 한 파일. Route Handler는 `parseJson(request, Schema)` 공용 함수로만 받는다.
