# ADR-008: 주소록 엑셀 파일 형식
- 상태: Accepted (user, 2026-10-21)
- 관련 계층: [어플리케이션]
- 근거: REQ-043, US-22, AC-22-1, RISK-07, NFR-13

## 맥락
의뢰인은 "엑셀로 한 번에 다운로드"를 원한다. 우편번호(`06234`)는 앞자리 0, 연락처는 하이픈이 있어 엑셀이 숫자로 바꾸면 깨진다. 관리자는 비전문가라 파일을 열자마자 바로 써야 한다.

## 검토한 옵션
| 옵션 | 장점 | 단점 | AI 부채 영향 | KANT 영향 | 되돌리기 비용 |
|---|---|---|---|---|---|
| A CSV(UTF-8 BOM), 의존성 0 | 패키지 추가 없음, 엑셀에서 열림 | 엑셀이 우편번호 앞 0을 지움 → 막으려면 `="06234"` 같은 우회 표기 필요 | 중 | 무관 | 낮음 |
| B `.xlsx` 생성: `exceljs` 1개 추가, 모든 칸을 텍스트 형식으로 | 우편번호·연락처가 그대로, 열 너비·머리글 서식 | 의존성 1개 (서버에서만 사용) | 낮음 | 무관 | 낮음 |

## 결정 / 추천
결정: **B `exceljs`** — 운영자가 손대지 않고 바로 송장 작업에 쓸 수 있다.

## 결과
- 생성 위치: `lib/data/addressBook.ts`(조회) + `app/api/admin/address-book/route.ts`(파일 응답, 메모리에서 바로 스트림, 서버에 파일 저장 안 함)
- 파일명: `ubuntubooks-address-book-YYYYMMDD.xlsx`
