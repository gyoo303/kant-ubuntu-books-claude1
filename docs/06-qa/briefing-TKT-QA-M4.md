## AI 부채 체크
- 사람이 이해하기 어려운 코드/과설계: #3의 원인이 `cn`이 세 군데 있는 데서 나온다(공통 C5). 버튼 모양이 "클래스를 더하면 덮어쓴다"는 가정에 기대는데, 실제로는 CSS 순서로 정해진다.
