## 5. 디자인 기준 핵심
- **팔레트·글꼴(UX-D-01)**: 종이·숲·밤하늘 팔레트. 제목·긴 글은 Gowun Batang, 본문·UI는 Gowun Dodum. 흰 페이지 바탕 금지. 등불색 `--lamp`는 창가 패널 안에서만.
- **UX-1~19 대표**: 토큰 외 색·임의값 금지(UX-1), 360px Header 두 줄·메뉴 숨김 없음(UX-2), 할인·순위·당일 표현 금지(UX-5), 노트 글자 크기(UX-6), 기본 버튼 1개 이하(UX-11), 언박싱 코드 숫자 키패드 한 칸(UX-12), 입력 오류와 칸 연결(UX-15), 반복 움직임은 촛불뿐(UX-17), 느낌표·이모지 금지(UX-19).
