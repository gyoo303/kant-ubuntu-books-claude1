- GATE-07 pgTAP: 사람이 SQL 편집기로 실행. 최종(DB-04) `admin_ops` 36 + `rls` 42 = 78개 통과. DB-02·03 시점에 `payments`·`state_machine`·`subscription` 테스트도 추가했다.

## 5. 설계와 다르게 한 것 (사용자 승인 포함)
- `types/product.ts`를 FE 대신 DB-01에서 만들었다(컴파일 순서 때문, 사용자 승인).
- `createPublicClient()` 추가: `'use cache'` 안에서는 `cookies()`를 쓸 수 없어서(사용자 승인).
- `book-covers` 버킷을 `0001`에, `postcards` 버킷을 `0030`에 넣었다(설계 문서 함께 수정).
- `lib/supabase/env.ts` 추가(설계 목록에 없던 작은 공용 파일).
- `server.ts`의 빈 `catch`는 Supabase SSR 가이드 형태라 GATE-06 예외로 기록했다.
- DB-02에서 정한 세부: `p_kind` 문자열, 배송지 jsonb 키, 멱등 반환(이미 목표 상태면 그 상태를 반환), 재고 없는 장바구니는 `OUT_OF_STOCK`, `begin_refund`는 `cancel_requested`에서만 시작.
- 미해결: 네이버 키 발급 전. 카카오·네이버가 닉네임을 어느 메타데이터 키로 주는지 확인 필요. `next.config.ts` 이미지 허용 주소는 FE에 넘김.
