## 3. 도메인 핵심 (Architect 인계 기준)
- **서비스 정의**: 대전 어은동 동네서점. 4개 테마(자연·식문화·생태·로컬) 책 판매 + 손편지 기반 블라인드 북 구독.
- **고정 제약**: Supabase(Postgres·Auth·Storage), Next.js App Router + TS + Tailwind, 기존 저장소 구조, 카카오·네이버 로그인만, 결제 테스트 모드, 4일차 시연.
- **핵심 엔티티**: Product, Cart, Order, Payment, ShippingAddress, Subscription, SubscriptionRound, ReaderLetter, ReplyLetter, PostcardPhoto, Teaser, UnboxingCode, ShelfMemo, FarewellNote.
- **상태 흐름**: 주문(결제 대기 → 접수 → 취소 요청 → 발송/환불), 회차 = 창가 등불(편지 도착 → 읽는 중 → 발송 → 언박싱, 되돌리지 않음).
- **주요 불변 규칙**: 결제 전 발송 금지(INV-04), 재고(INV-05), 중복 확정 금지(INV-06), 블라인드·코드(INV-07·08), 등불 단방향(INV-09), 관리자 전용(INV-15), 편지류 열람 제한(INV-19), 취소 요청 중 발송 금지(INV-20).
