## 6. 설계에 없어 정한 것
- `authorizeKeeper()` 추가: 책방지기 액션은 `notFound()` 대신 `FORBIDDEN`을 `ActionResult`로 돌려준다.
- 결제창 상품명: "첫 책 외 N권" / "우분투북스 편지 구독". `customerKey`는 회원 id.
- `lib/supabase/proxy.ts`는 HANDOFF 산출이라 BE가 썼다(지도상 DB 영역).
- 장바구니 변경 뒤 `refresh()`로 Header 개수를 다시 그린다.
- `list_shipping_targets` 생성 타입과 실제 null 값 차이를 `?? null`로 받는다.
